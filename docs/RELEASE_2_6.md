# Academia Flow 2.6 — Rotina Inteligente

A versão 2.6 prioriza utilidade diária e mantém o funcionamento offline-first.

## Principais novidades

- Hoje 2.0 com resumo contextual, carga do dia e prioridades.
- Planejador semanal com blocos de estudo persistentes.
- Foco inteligente de atividades por urgência, atraso, prazo e prioridade.
- Ações rápidas para duplicar e adiar atividades.
- Presença 2.0 com revisão, motivo/observação e opção de desfazer alterações.
- Projeção de frequência após uma nova falta.
- Laboratório de notas com cálculo da nota necessária na próxima avaliação.
- Nota rápida vinculada automaticamente à aula atual.
- Central de avisos acadêmicos baseada em prazos, provas, presença, estudo e risco.
- Novos testes para modelos do planejador e algoritmo de priorização.

## Compatibilidade

- Mantém SQLite como fonte principal para os dados acadêmicos existentes.
- Os blocos do planejador e avisos dispensados usam persistência leve nas configurações locais.
- Não exige conta, servidor ou internet para os novos recursos.
- A versão não introduz recursos específicos adicionais para Windows; o código compartilhado continua compatível com os builds existentes.
