ACADEMIA FLOW 2.0 - ENVIAR PELO CELULAR / TERMUX

1) Entre em Downloads:
cd ~/storage/downloads

2) Entre na pasta extraida:
cd academia_flow_ready_use

3) Se aparecer "detected dubious ownership":
git config --global --add safe.directory "$(pwd)"

4) Inicialize e envie:
git init -b main
git add .
git commit -m "Academia Flow 2.0 - pronto para uso"
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main

SE O ORIGIN JA EXISTIR:
git remote set-url origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main
